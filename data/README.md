# Data

This directory contains the raw, processed, and sampled data used throughout the notebooks in the NYC street vendor enforcement analysis. Raw data is not committed to version control (see `.gitignore`); this README documents provenance and how to reproduce each dataset locally.

## Directory structure

```
data/
  raw/
    311_requests/
      requests_2010_2019.csv
      requests_2010_2025.csv
      requests_2020_2025.csv
    BIDS/
      BID shapefiles (.cpg, .dbf, .prj, .shp, .shx)
    census_tracts/
      census tract shapefiles (.dbf, .prj, .shp, .shp.xml, .shx)
    council_districts/
      council district shapefiles (.dbf, .prj, .shp, .shp.xml, .shx)
    PLUTO/
      pluto_26v1.csv
      pluto_datadictionary.pdf
      pluto_readme.pdf
    original_OATH_df.csv
    respondent_geocoded.csv
    violation_geocoded.csv
    acs_2024.csv
  processed/
    acs_2024_tracts.geojson
    cc_analysis.geojson
    council_votes.csv
    district_scores.csv
    enacted_bills.csv
    sensitivity_311_to_violations.csv
    violations_df_full.csv
  sample/
    original_OATH_df_sample.csv
    requests_2010_2025_sample.csv
    violation_geocoded_sample.csv
```

## Datasets to Download Directly

| Dataset | Source | save_as |
|---|---|---|---|
| Council District boundaries | [NYC Department of City Planning - City Council Districts](https://www.nyc.gov/content/planning/pages/resources/datasets/city-council) | council_districts |
| BID boundaries | [NYC Open Data](https://data.cityofnewyork.us/Business/Business-Improvement-Districts/7jdm-inj8/about_data) | BIDS |
| PLUTO | [NYC Department of City Planning - PLUTO, MapPLUTO, and PLUTO Change File](https://www.nyc.gov/content/planning/pages/resources/datasets/mappluto-pluto-change) | PLUTO |
| NYC Census Tracts | [NYC Department of City Planning - Census Tracts](https://www.nyc.gov/content/planning/pages/resources/datasets/census-tracts) | census_tracts |


## Reproducing API-Pulled Raw Data

The three additional API-pulled raw datasets (`original_OATH_df.csv`,`311_requests` folder, and `acs_2024.csv`) can be regenerated by running the notebooks.

## Coordinate reference system

All spatial layers are either natively in or are projected to **EPSG:2263** (NAD83 / New York Long Island, feet).

## Processed data

All processed files are built from raw data in the notebooks. Descriptions and explanations are found in the notebooks as well.
